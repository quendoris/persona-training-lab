# Methodology limits

Эта система измеряет поведение языковой модели в заданном тестовом протоколе. Она не является клинической диагностикой человека.

## Текущие ограничения

1. Короткая батарея даёт быстрый KPI, но не заменяет полную валидированную методику.
2. Модель может подстраиваться под формат prompt, поэтому важно фиксировать generation config.
3. Score отражает ответ модели на пункт, а не внутреннее состояние модели в психологическом смысле.
4. Для публикации нужны повторные прогоны и статистика стабильности.
5. Для сравнения версий нужно использовать одну и ту же батарею и scoring rules.

## Что улучшать дальше

- добавить полную открытую IPIP-батарею;
- хранить generation config рядом с результатом;
- добавить повторные прогоны с одинаковыми seed/режимами;
- считать стабильность score между повторениями;
- добавить ручную экспертную разметку качества ответов;
- экспортировать результаты в CSV/JSONL для анализа.

## Безопасная формулировка результата

Корректно:

```text
Модель версии X в протоколе Y получила такие Big Five KPI.
```

Некорректно:

```text
У модели настоящая клиническая личность такого-то типа.
```
