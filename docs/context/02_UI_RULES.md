# Persona Training Lab — UI Rules

## 1. Язык
- интерфейс: русский
- код, имена файлов, внутренняя логика: английский

## 2. Главный визуальный принцип
Интерфейс должен ощущаться как спокойная, дорогая, исследовательская станция. Не кричащая, но очень собранная.

## 3. Shell containers
Для длинных списков и блоков используется крупный внешний shell-контейнер:
- скруглённый
- без лишнего мусора внутри
- тема берётся из theme manager
- внутренние обёртки прозрачные

## 4. Как работать с внутренними прямоугольниками
Если внутренний прямоугольник:
- дублирует внешний shell
- даёт лишний тёмный фон
- ломает light theme
то его нужно убирать.

## 5. Поведение текста
### Смысловые карточки
Если текст передаёт мысль внутри карточки, его лучше переносить на новую строку.

### Summary / узкие статусы
Если элемент должен быть компактным, допустимо использовать elide (`...`), но только по фактической ширине контейнера.

## 6. Sidebar
- icons sidebar: простые, чистые, единый набор SVG
- brand icon: может быть сложнее и выразительнее
- активная кнопка должна оставаться читаемой и не перетягивать внимание лишним шумом
- layout sidebar должен выдерживать уменьшение окна без расползания текста

## 7. Светлая / тёмная тема
Light/dark поведение должно жить через theme manager.
Запрещено:
- жёстко вшивать тёмный rgba-фон в screen helpers
- дублировать цвета прямо в локальном setStyleSheet, если это общий паттерн

## 8. Cards and spacing
- внешние карточки держат общую композицию
- внутренние карточки должны иметь воздух
- текст не должен прилипать к краям
- большие shell-контейнеры должны растягиваться вниз, а не просто обнимать контент

## 9. Иконки
- SVG
- прозрачный фон
- единый stroke
- `currentColor`
- без цветных заливок и тяжёлых декоративных эффектов
