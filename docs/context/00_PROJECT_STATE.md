# Persona Training Lab — Project State

## 1. Назначение проекта
Persona Training Lab — desktop-first исследовательская станция под Linux для обучения устойчивой личности модели, контроля качества датасетов, фиксации snapshot-состояний, проведения тестов и анализа изменений между версиями.

## 2. Главная продуктовая цель
Система должна помогать не просто запускать fine-tune, а сопровождать полный жизненный цикл формирования личности модели:
- curated datasets
- training runs
- snapshots
- tests
- analysis / compare
- встроенная документация и управляемая тема интерфейса

## 3. Что уже реализовано
- shell с левой панелью навигации и модульными окнами
- русскоязычный интерфейс
- theme manager и несколько тем
- модули: Dashboard, Profiles, Datasets, Training, Snapshots, Tests, Analysis, Style, Docs
- крупные scroll-shell контейнеры для длинных блоков
- SVG-иконки для sidebar и отдельная brand-иконка
- git workflow для работы через baseline + patch/diff
- локальная документация проекта в папке docs/context

## 4. Что считаем актуальной рабочей опорой
- базовая полная версия: phase 2.9
- дальнейшая работа идёт через git-ветку и patch/diff
- если правка применена, проверена и нравится обоим авторам, она фиксируется как новая правда проекта

## 5. Что ещё в развитии
- окончательная доводка light theme
- финальная полировка sidebar icons / brand block
- ревизия старой документации и перенос в новый актуальный контекстный пакет
- настройка рабочего режима с Codex как код-исполнителем, а не автором продуктовых решений

## 6. Принцип работы
Авторы проекта принимают продуктовые, архитектурные и визуальные решения. Codex и другие инструменты выступают как исполнительный слой для кода и механических задач. Авторство, направление и финальная валидация остаются у людей.

## 7. Текущий инженерный ритм
- baseline в git
- отдельная рабочая ветка
- обмен через patch/diff вместо больших архивов
- после удачного шага — commit и фиксация нового состояния

## 8. Главное ограничение
Никакие локальные визуальные hardcode-стили не должны подменять theme manager там, где нужен нормальный light/dark switching.
