# Persona Training Lab v0.1.0 — release checklist

## Purpose

This is the checklist for the **first public Persona Training Lab release after the large architecture/refactor cycle**, not a pre-refactor milestone.

The goal of v0.1.0 is to freeze one coherent desktop research workstation whose implemented behavior, documentation, runtime-safety contracts and package artifacts agree with each other. It is not a claim that the future mathematical/research program is complete.

## Release identity

- Working branch: `agent/history-keyguard-poller`
- Package version: `0.1.0`
- Runtime version: `persona_training_lab.__version__ == "0.1.0"`
- Latest clean quick-gate evidence before this documentation pass: `39d25de13568571a019992fe84ec8a616b6e7048`
- That quick gate: compileall PASS, Ruff PASS, typing audit PASS with zero blocking findings, **603 passed ×3**, i18n audit PASS, docs audit PASS, clean codebase statistics.
- Final release evidence **must be rerun on the final tagged commit**; evidence from `39d25de...` becomes historical as soon as this checklist/documentation changes.

## Scope freeze

Until v0.1.0 is tagged:

- do not add Training Dynamics runtime features;
- do not start the Mathematical Inspector implementation;
- do not expand product scope merely because an architecture could be cleaner;
- change runtime code only for a concrete audit/test/documentation/packaging finding;
- convert repaired release-critical cracks into permanent regression/audit coverage.

The proposed Training Dynamics mathematics and instrumentation documents remain research specifications, not v0.1.0 runtime claims.

## Explicit non-goals for v0.1.0

The first release does not claim:

- completed Training Dynamics runtime instrumentation;
- a Mathematical Inspector;
- exhaustive adversarial/stress/falsification coverage;
- bit-identical ML reproducibility across arbitrary hardware/software stacks;
- cryptographic content addressing of complete base-model or trained-artifact directories;
- sandboxing of trusted-host Automation;
- distributed workers or multi-host locking;
- scientific proof of the psychological methodology;
- autonomous-agent interaction experiments.

Those are later research/development layers built on top of the frozen v0.1.0 foundation.
