# v0.1.0 shell audit

This document records release-shell findings separately from the final checklist.
An item is closed only after the implementation and its local acceptance test
both succeed.

## Scope

- application identity and settings location;
- main-window geometry;
- dock placement, visibility, floating state and sizes;
- current workspace restoration;
- sidebar data integrity;
- clean shutdown of shell timers and temporary visual effects;
- first-pass removal of demonstrational shell remnants.

## Storage contract

The shell uses Qt-native settings and stores only:

- `shell/window_geometry`;
- `shell/dock_state`;
- `shell/current_workspace`.

Model data, runtime operations, key bindings and lineage state remain in their
existing dedicated stores. Window-state corruption is treated as recoverable:
invalid byte arrays are ignored and the default layout is used.

## One-command audit

Quick release-shell pass:

```bash
uv run python tools/release_gate.py --quick
```

Full current gate:

```bash
uv run python tools/release_gate.py
```

Repeated deterministic pytest passes:

```bash
uv run python tools/release_gate.py --runs 3 --seed 4102026
```

Each invocation writes an isolated report under:

```text
artifacts/release-audit/<timestamp>-<commit>-seed-<seed>/
```

The directory contains metadata, one combined stdout/stderr log per step, and
machine-readable plus Markdown summaries. Mypy is informational by default;
compileall, Ruff, pytest, codebase statistics and build are blocking in the full
gate.

## Manual shell acceptance route

1. Start the application and open every dock.
2. Float Inspector and move it to a different position.
3. Hide Problems, leave Activity visible and select Agents.
4. Resize the main window and change the relative dock sizes.
5. Close normally and restart.
6. Confirm geometry, selected workspace, dock visibility, floating state and
   sizes are restored.
7. Return all panels to their default arrangement and repeat once.
8. Switch theme, accent and UI scale; confirm the restored layout remains usable.
9. Run rapid canvas zoom/pan/drag gestures and check for delayed movement after
   input stops.
10. Close from a workspace with a leave guard and verify that rejected shutdown
    does not overwrite the last accepted shell state.
