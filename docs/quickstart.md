# Quickstart

Persona Training Lab — локальная лаборатория для обучения, проверки и сравнения версий модели.

## Быстрый маршрут

1. Откройте вкладку **Датасеты** и добавьте JSONL/JSON dataset.
2. Проверьте, что структура валидна: нужны поля `prompt` и `response`.
3. Откройте **Обучение**, выберите профиль, датасет, модель и параметры запуска.
4. Запустите fine-tune и дождитесь строки `Artifact saved`.
5. Откройте **Снимки** и проверьте, что новая версия модели зарегистрирована.
6. Откройте **Тесты** и нажмите **Собрать портрет**.
7. Откройте **Анализ** и проверьте Big Five KPI и дельту относительно предыдущего портрета.

## Минимальная проверка перед работой

```bash
uv run python -m compileall src tests
uv run python -m pytest
uv run python -m persona_training_lab.bootstrap.app
```

## Что считать успешным прогоном

- обучение завершилось без блокировки UI;
- artifact сохранён в `artifacts/full_finetune/.../model`;
- портретные тесты вернули `VALID_SCORE: 1`;
- анализ показывает KPI, а не `нет score`;
- при наличии двух портретов анализ показывает `latest - previous`.
