# Experiment protocol

Этот протокол нужен, чтобы результаты можно было сравнивать между версиями модели.

## Единица эксперимента

Один эксперимент — это связка:

```text
base_model + dataset_version + training_config + artifact + portrait_battery + scoring_version
```

## Перед обучением

1. Зафиксировать исходную модель.
2. Зафиксировать датасет и его структуру.
3. Записать параметры обучения: epochs, batch size, learning rate.
4. Прогнать baseline portrait, если нужен расчёт дельты.

## После обучения

1. Проверить наличие artifact.
2. Проверить, что локальная модель отвечает.
3. Собрать Big Five portrait.
4. Открыть анализ и проверить KPI.
5. Если есть baseline, смотреть delta факторов.

## Что сохранять для статьи

- версия модели;
- версия датасета;
- версия батареи тестов;
- версия scoring;
- параметры генерации;
- raw responses;
- валидные score;
- reverse-score значения;
- итоговые KPI;
- delta относительно baseline.

## Что нельзя смешивать

- training run и test run;
- старый портрет и новый портрет без версии батареи;
- валидный score и raw text;
- оценку модели и клиническую диагностику человека.
